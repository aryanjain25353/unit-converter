# CLI Bill Generator with Rush Hour Pricing 🧾

A lightweight, terminal-based Python application designed to generate retail invoices, calculate tax rates (GST), apply discounts, handle dynamic surge pricing, and export formatted receipts.

## Key Features
- **Zero External Dependencies:** Built purely with Python standard libraries (no classes, simple loops and functions).
- **⚡ Rush Hour Surge Toggle:** Optional +10% dynamic pricing adjustment during peak demand.
- **Custom Tax & Discounts:** Itemized GST percentage application and flat order discounts.
- **Automatic Receipt Export:** Saves each transaction as a formatted `.txt` bill file.

## How to Run
1. Ensure Python is installed on your computer.
2. Download or copy the code from `bill_generator.py`.
3. Run the script in your terminal:
```bash
python bill_generator.py
